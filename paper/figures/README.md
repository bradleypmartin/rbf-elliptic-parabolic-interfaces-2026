# paper/figures/

The manuscript's figures (`*.pdf`) and booktabs table fragments (`tab_*.tex`),
generated by `scripts/paper_figures.py` (E5.3, #44) from the results files in
`../data/` alone and never hand-edited. `docs/figures/` holds the notes' PNG
versions, which the drivers draw for the screen; these are the same data laid
out again for print: `plotting.use_print_style()` (serif, 8 pt beside the 11 pt
body, 7 pt ticks and legends), exactly `\textwidth` wide (amsart 11 pt, 360 pt)
so that `\includegraphics{name}` sets them at their natural size, the notes'
colours and markers. `SOURCE_DATE_EPOCH` is pinned, so a regenerated file is
byte-identical to the committed one.

```sh
uv run python scripts/paper_figures.py           # every file, a few seconds
uv run python scripts/paper_figures.py --check   # byte identity; make_arxiv's gate
uv run python scripts/paper_figures.py --only heat2d_stiff_knee.pdf
```

`--check` draws everything into a temporary directory and fails on a file that
differs, one that is missing, and a `*.pdf` or `tab_*.tex` here that the script
does not register. Names carry no dot but the extension's (`\includegraphics`
would read `a0.02` as one), so case 2's figures are `…_curved`.

## Table fragments

One booktabs `tabular` each (`scripts/paper_tables.py`), no float and no
caption: the text wraps it in a `table` at `\footnotesize` (a few are wider
than the text at `\small`). The first line is `% GENERATED …`, naming the
files and the notes section; the `%` lines after it say what the caption must
(columns, norm, counts). Errors print as `$\sci{m}{e}$` (`main.tex`'s macro) to
the notes' three figures, fitted orders to two decimals. They mirror the notes'
tables, so that every number of the closing statements (stiff §2.5's four,
§5.1's snapshot, §5.3's eleven) can be read off one of them. None prints a run
time: timings are the notes' to quote, since a rerun of the documented commands
would not reproduce them.
