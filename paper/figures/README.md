# paper/figures/

Figures (`*.pdf`) and booktabs table fragments (`tab_*.tex`) the manuscript
includes. Generated by `scripts/paper_figures.py` (E5.3, #44) from `data/`
and the drivers, never hand-edited; `--check` regenerates them and fails on
any byte that differs. `docs/figures/` holds the notes' PNG copies.
Empty until E5.3.
