# paper/: the manuscript (epic E5, #7)

The arXiv write-up of this repository: the 2016–2017 RBF-FD heat-transfer
construction, ported and verified (`docs/port-notes.md`), and the seed
stencils for sub-grid smooth edges (`docs/stiff-diffusion.md`), elliptic and
parabolic, in 1-D and 2-D. Scaffolded in E5.1 (#42); the sections are drafted
one ticket at a time (table below). The layout follows the companion wave
manuscript's `paper/`.

**Novelty is cited, not claimed.** [`LITERATURE.md`](../LITERATURE.md) at
the repository root (E5.2, #43) is the novelty ledger. Its §6 holds the only
novelty wording the manuscript may use: §6a the prior-work paragraph, §6b
the claim sentences and their required caveats. Its §1d records what the
pass decided: plan R1 is answered (the 1-D construction is classical; the
claim is two-dimensional and scoped to stencils) and T3 is dropped.

**Licensing.** `paper/` (`main.tex`, `references.bib`, `main.pdf`, `figures/`,
`data/`) is [CC BY 4.0](LICENSE); the code in the rest of the repository is
MIT (see the root [README](../README.md)).

## Source-of-truth rule

`docs/stiff-diffusion.md` is canonical for the stiff-edge study and
`docs/port-notes.md` for the port (plan D11). The manuscript **quotes** them
and never becomes a second source of truth. Every number in `main.tex`
carries a `% TRACE` comment naming the notes section or the results file it
comes from; `scripts/paper_numbers.py` (E5.3, #44) asserts the ones the
results files hold, and the assembly pass (E5.10, #51) re-checks all of them.
Where the files and the notes disagree, the notes are corrected, not the
manuscript alone.

## Data, figures, tables and numbers (E5.3, #44)

Three scripts at the repository root, each with a test file:

```sh
uv run python scripts/paper_data.py            # rerun the 22 documented runs into data/
uv run python scripts/paper_data.py --verify   # each file its run's, clean, in HEAD's history
uv run python scripts/paper_figures.py         # figures/ from data/ (a few seconds)
uv run python scripts/paper_figures.py --check # byte identity with figures/
uv run python scripts/paper_numbers.py         # every cache-backed number against data/
```

- **`paper_data.py`** holds `RUNS`, the documented commands (stiff note §2.5,
  §5.1's table, the ring's docstring), and reruns them from the working caches
  under `outputs/` (about ten minutes, most of it the one uncached run). It
  refuses a tree with uncommitted changes outside `data/`, since the files
  record the commit and the dirty flag. `--verify` refuses a file that is not a
  documented run's, was written from another command line (`argv`, schema 2),
  from a dirty tree or at a commit outside HEAD's history.
- **`paper_figures.py`** draws every figure and fragment from `data/` alone:
  the figures in print style at `\textwidth`, the fragments as booktabs
  `tabular`s with `\sci{}{}` numbers and a `% GENERATED` header naming their
  files. `SOURCE_DATE_EPOCH` is pinned, so `--check` compares bytes.
- **`paper_numbers.py`** runs `paper_data`'s verification, then checks each
  quoted figure against the unrounded value the files give (half a unit in the
  last quoted digit; `<=` and `>=` for bounds). Its checks carry the notes
  section they verify (`stiff §5.3 (4)`); a drafting ticket that quotes one
  prepends the manuscript's section, and one that quotes a new cache-backed
  number adds a check.

The manuscript never reads `outputs/`. Rebuild order after a change to a
driver: commit, `paper_data.py`, `paper_figures.py`, `paper_numbers.py`, commit
`data/` and `figures/` together.

## Build

```sh
cd paper/
SOURCE_DATE_EPOCH=0 tectonic main.tex                        # the committed main.pdf
SOURCE_DATE_EPOCH=0 tectonic --keep-intermediates main.tex   # also keeps main.bbl (packaging)
```

With `SOURCE_DATE_EPOCH` pinned the PDF is byte-identical from build to build
(tectonic 0.17.0), so an unchanged source never shows up as a changed
`main.pdf`; without it only the PDF's timestamps and ID differ. The `\date` is
fixed by hand, never `\today`, and moves with content changes. After any edit
under `paper/`, rebuild, look at the changed pages (`pdftoppm -r 60 -png
main.pdf /tmp/p`), and commit `main.pdf` with the source. Intermediates
(`.aux`, `.bbl`, `.log`, …) and the arXiv tree are gitignored.

**Pitfall (found in the companion, tectonic 0.16.9).** Its BibTeX hung
forever, at full CPU with no log, on an `amsalpha` label whose three-letter
prefix held a braced accent in a single author's surname (`P{\'o}lya`). The
companion writes those surnames as UTF-8 (`Pólya`, `Mühlbach`), which label as
`[Pó22]` and `[Mü73]`; `make_arxiv.py` checks that such labels render. Not
yet tested on 0.17.0; if a build spins for more than a minute, bisect
`references.bib`.

## Packaging for arXiv

```sh
cd paper/
SOURCE_DATE_EPOCH=0 tectonic --keep-intermediates main.tex
uv run python make_arxiv.py
```

arXiv runs no BibTeX, so the upload carries `main.bbl`. The script refuses, in
this order:

1. **a draft**: a `\stub`, `\todo` or `\nocite{*}` outside a comment in
   `main.tex` (the scaffold's `\stub` macro definition counts, so it goes with
   the last stub), or a bibliography entry without a dated `VERIFIED` note in
   the comment lines directly above it, or one still saying `TODO(verify`.
   Every line opening with `@` counts as an entry (`@comment`, `@string`,
   `@preamble` aside), and a header the gate cannot read is refused, not
   skipped. These gates run whatever the flags;
2. **failed repository checks**: `scripts/paper_numbers.py --quiet` and
   `scripts/paper_figures.py --check` (E5.3, above), run from the root;
3. **a lossy transform**: it stages `main.tex` and `references.bib` with their
   whole-line comments stripped (the `% TRACE` and `VERIFIED` notes are for
   the repository, not the paper), the `.bbl`, and every figure and fragment
   the source names into `arxiv/`, refuses any character arXiv's pdfTeX would
   not read, rebuilds the staged tree in a scratch copy and compares its text
   with the committed `main.pdf`.

Then it writes `arxiv.tar.gz`. `--no-verify` skips 2 and the rebuild of 3;
`--keep-comments` stages the sources verbatim. Until the sections are drafted
the script stops at gate 1, on the stubs; since E5.2 the bibliography passes
it.
